Privacy Policy - yt-mcp

Last updated: 2026-10-28

This application is used only by the operator of a YouTube channel to upload, schedule and manage videos on that channel through the YouTube Data API.

Data accessed

With the channel owner's consent, the app uses Google OAuth to access the owner's own YouTube account in order to upload videos, set their visibility and publish time, and read their status.

Storage

OAuth tokens are stored only on the operator's own computer. No data is stored on any server operated by this app.

Sharing

No data obtained through Google APIs is sold, shared with or transferred to any third party.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.
